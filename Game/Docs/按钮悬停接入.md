# 框架按钮悬停

`FCCommonUICompClass` 创建时自动启动 `Client/FCButtonHover.lua`，无需项目逐个绑定按钮。组件析构时解除监听并恢复比例。

- 覆盖所属 `PlayerGui` 下现有和后续新增的 `TextButton`、`ImageButton`；不覆盖 Roblox `CoreGui`。
- 鼠标进入放大到原比例的 `1.05` 倍，耗时 `0.12` 秒；移出在 `0.10` 秒内恢复。
- 按钮或父界面隐藏、按钮禁用时立即复位；移出 `PlayerGui` 时解除绑定。
- 默认使用按钮自身的 `UIScale`，不存在时创建；不改变 `Size`、`Position` 或 `AnchorPoint`。

特殊按钮的 Attributes 在挂入 `PlayerGui` 前设置：

- `HoverEnabled = false`：排除全屏遮罩等不应缩放的按钮。框架通用弹窗遮罩已自动排除。
- `HoverTargetParent = true`：透明点击区缩放其直属 `GuiObject` 父容器，使背景、图标和文字一起变化；同一容器只指定一个点击区。

若其他动画也控制同一 `UIScale`，应调整目标或排除该按钮，避免同时控制比例。父容器开启 `ClipsDescendants` 时需为放大效果留出边距。
