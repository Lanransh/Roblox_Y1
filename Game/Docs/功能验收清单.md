# 功能验收清单

仅记录当前已实现功能；勾选表示验收通过，只能由用户或用户明确授权的 AI 勾选。代码改动后受影响项自动取消勾选，需重新验收。

## 系统功能验收清单

### 石头关卡

- [ ] 攻击目标：检测角色水平正前方 3 studs 所在格，每次最多伤害一块石头。
- [ ] 无效攻击：命中时已离开原目标、卸下镐子或死亡，不扣血、不增加击打训练值。
- [ ] 石头血量重置：回到起点安全区或重生时，恢复个人石头血量并清理未拾取掉落；离服也清理。待重新验收：新增掉落清理。
- [ ] 随机掉落与拾取：击破后客户端请求该石头道具，服务器仅处理一次随机结果；道具向上弹出并落下，随后与 ItemHUD 一起持续上下漂浮，HUD 展示名称、原模型档次和随机价格，隐藏未启用的计时文本；拥有者靠近按 E 拾取，拒绝他人、死亡、超距和重复领取，背包满时保留漂浮掉落，拾取或重置时停止动画。入口：[石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.lua)。待重新验收：新增往返漂浮及动画清理。

### 等级与训练

- [ ] 训练值保存到存档，等级与力量由训练值派生；存活时自动训练，走路不额外增加训练值，点击屏幕增加训练值，击打收益保留。待重新验收：训练触发方式调整。
- [ ] 主界面同步等级、力量、当前等级经验及满级文案；进度条平滑填充。点击收益图标从实际点击位置飞向屏幕中央；自动训练和击打收益仍从中心散开后飞向力量栏。动画由服务端确认收益后触发，首次读档不播放。入口：[CMain](../StarterPlayer/StarterPlayerScripts/Client/UI/CMainUICompClass.lua)。待重新验收：点击飞行路线、鼠标与触屏坐标、连续点击及自动收益同时发生。

### 道具与背包

- [ ] 免费镐子：出生及重生自动发放并装备，攻击石头不消耗镐子。
- [ ] 测试方块（1001）和测试球（1002）使用时显示提示。
- [ ] 测试道具发放：仅 Studio 空背包发放测试方块 1 个、测试球 3 个。

## 数值验收清单

### 石头关卡

- [ ] 关卡石头血量：共 13 关，单块血量从 29 到 8.44 亿，逐关按[血量表](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.lua)核对。
- [ ] 关卡推荐等级：`（关卡序号 − 1）× 15`。
- [ ] 等级攻击力：`向下取整（10 × 1.1^等级）`。
- [ ] 单次伤害：`攻击力 × max（0，1 − max（0，推荐等级 − 玩家等级）× 0.07）`，每落后一级减伤 7%。
- [ ] 攻击间隔：每 0.8 秒最多攻击一次，残血击破也遵守间隔。
- [ ] 掉落原型：每块石头击破时独立以 50% 概率生成 1 件；从现有 208 个收藏品中等概率选择，价格均匀随机整数 10～1000；重复请求不重抽；弹起 4 studs，0.25 秒上升、0.35 秒落下，此后向上漂浮 0.8 studs，单程 1.3 秒，Quad InOut 无限往返，可在 10 studs 内按 E 拾取。依据：[原型参数](../ServerScriptService/Server/Player/RockCollectible.lua)及石头组件。待重新验收：新增漂浮幅度与周期；概率与价格仅为功能演示。

### 等级与训练

- [ ] 等级范围：初始 1 级，上限 780 级。
- [ ] 自动训练收益：存活期间每秒训练值 +2，静止与行走相同；死亡期间不累计。依据：NumericalConfig.trainingSettlementsPerSecond。待重新验收。
- [ ] 点击训练收益：每次有效点击训练值 +2，服务端每 0.2 秒最多结算一次；按钮、输入框、触屏摇杆操作不触发训练。依据：[RockLevel](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.lua)。待验收。
- [ ] 击打训练收益：每秒有有效命中则训练值 +2，同秒多次命中不重复增加。
- [ ] 混合训练收益：自动训练与有效击打合计每秒 +4，点击收益额外叠加；力量仍按等级曲线派生，不直接按秒加力量。待重新验收。
- [ ] 单级升级需求：`四舍五入（等级^p）`，p 按[等级曲线配置](../ReplicatedStorage/Scripts/Game/Configs/NumericalConfig.lua)分段线性插值，区间外取端点。
- [ ] 累计升级门槛：升到 L 级需要累计第 1～L−1 级的升级需求。

### 道具与背包

- [ ] 测试方块（1001）：每格最多 1 个，使用不消耗。
- [ ] 测试球（1002）：每格最多 10 个，每次使用消耗 1 个。
- [ ] 收藏品（1003）：每格 1 件，不堆叠；价格保存在该件道具的额外数据中，不增加或扣除货币。依据：[道具配置](../ReplicatedStorage/Scripts/Game/Configs/ItemConfig.lua)。待重新验收。
- [ ] 快捷栏容量：默认开启，共 10 格；关闭时为 0 格。
- [ ] 背包容量：默认 50 格，与快捷栏合计 60 格；背包容量可配置为 0。
- [ ] 战利品背包容量：12 件，沿用 Studio_Y3 库存容量；满时保留场景掉落，回基地后只移除成功转入正式背包的记录。依据：[RockLevel](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.lua)。待验收。
