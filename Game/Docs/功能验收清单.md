# 系统验收清单

仅记录已实现系统的关键功能与核心数值，不记录小细节调整及普通 bug 修复。勾选由用户或用户明确授权的 AI 完成；核心规则变化或原验收结论失效时，相关系统项需重新验收。

## 系统功能验收清单

- [ ] **石头关卡**：石头正常加载，自动攻击、扣血、击破和秒杀穿行正常；回安全区或重生后恢复个人关卡状态，无效攻击不结算伤害。入口：[石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.lua)。
- [ ] **等级与训练**：走路和有效击打获得训练值并升级；点击不增加实际收益；主界面正确显示等级、力量和经验，重登恢复训练进度。入口：[石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.lua)、[主界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CMainUICompClass.lua)。
- [ ] **道具与背包**：出生与重生获得镐子；击破石头随机掉落收藏品，仅拥有者可拾取；战利品可查看并在回基地后转入正式背包，满包不丢失、不重复领取；收藏品可装备，重生与重登后名称、价格和库存正确恢复。入口：[石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.lua)、[背包适配](../ServerScriptService/Server/Player/SPlayerObjectClass.lua)。
- [ ] **钻石**：主界面正确显示余额，重登保持存档余额。入口：[主界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CMainUICompClass.lua)。

## 数值验收清单

- [ ] **石头关卡**：13 关血量、推荐等级、攻击力与等级差减伤符合[关卡配置与公式](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.lua)；普通攻击间隔 0.8 秒，伤害达到满血秒杀条件时每 0.1 秒最多击破一块。
- [ ] **等级与训练**：初始 1 级、上限 780；升级需求与累计经验符合[等级曲线配置](../ReplicatedStorage/Scripts/Game/Configs/NumericalConfig.lua)；每秒走路 +2、有效击打 +2，同时成立合计 +4，点击不叠加收益。
- [ ] **道具与背包**：每块石头掉落概率 50%，收藏品等概率选择，价格为 10～1000 随机整数并随道具保存；战利品容量 12 件，正式背包默认 50 格、快捷栏默认 10 格，收藏品每格 1 件、不堆叠；拾取与入库不直接增加货币。依据：[掉落参数](../ServerScriptService/Server/Player/RockCollectible.lua)、[关卡配置](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.lua)。
- [ ] **钻石**：新玩家初始 500，已有存档余额不重置。依据：[玩家数据配置](../ReplicatedStorage/Scripts/Game/Shared/PlayerDataConfig.lua)。
