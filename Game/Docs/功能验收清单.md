# 功能验收清单

仅记录当前已实现玩法，以玩法系统为整体验收单位。勾选表示验收通过，只能由用户或用户明确授权的 AI 勾选；改动影响玩法行为或数值结果后，受影响项自动取消勾选，需重新验收。纯框架整理、日志等不影响玩法的改动不列项。

## 系统功能验收清单

- [ ] 测试道具与原生背包：默认开启时，Studio 空背包发放测试道具，玩家可通过原生背包选择并使用；`SetupProvider.lua` 的 `GetNativeBackpackConfig()` 返回 `ShortcutEnabled = false` 时不生成框架手持 Tool，客户端不绑定手持输入，服务端拒绝 ActivateTool；道具数据、发放和服务端直接 UseItem 保留。InventoryCapacity 配置框架背包容量，0 表示关闭；快捷栏关闭或背包容量为 0 时同时隐藏原生快捷栏及背包面板，只关闭面板时输出限制警告。原生界面无法独立隐藏其中一个。入口：`ReplicatedStorage/Scripts/Framework/FClient.lua`、`ReplicatedStorage/Scripts/Framework/Client/FCNativeBackpack.lua` 和 `ServerScriptService/Server/Player/SPlayerObjectClass.lua`。SetupProvider 直接返回快捷栏布尔开关和背包容量，待重新验收手持控制、容量为 0 及格子边界。

- [ ] 排行榜：MiniStudio 的月度 Playtime 时长榜配置已接入现有房间/全局排行榜服务，榜单索引为 1；服务端业务写分后可通过 C2S_RankingData 查询。入口：`ReplicatedStorage/Scripts/Game/Shared/RankingDataConfig.lua`、`ServerScriptService/Server/Service/SRankingServiceClass.lua`。仅恢复榜单配置和服务接入，未添加时长累计或项目榜单 UI；待验证写分、查询、重进和跨月切榜。

## 数值验收清单

- [ ] 测试道具与原生背包：`SetupProvider:GetNativeBackpackConfig()` 返回 `ShortcutEnabled` 和 `InventoryCapacity`；快捷栏开启时固定 10 格，关闭时 0 格，背包默认 50 格，默认总容量 60；依据 `ServerScriptService/Server/Player/SPlayerObjectClass.lua` 的 `Inventory:GetConfig()`。待重新验收快捷栏开关、背包容量为 0、第 10/11 格边界、总容量及旧存档道具完整性。

- [ ] 排行榜：时长榜分数按秒存储（unit = 1），降序，最多 100 条，月度切榜、保留历史最高分，默认分数 0。依据：源 MiniStudio RankingDataConfig，当前配置入口为 `ReplicatedStorage/Scripts/Game/Shared/RankingDataConfig.lua`；待实际运行验证，构建不代替数值验收。

其他玩法数值尚未盘点。
