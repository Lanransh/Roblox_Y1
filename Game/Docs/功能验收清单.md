# 系统验收清单

仅记录已实现系统的关键功能与核心数值，不记录小细节调整及普通 bug 修复。勾选由用户或用户明确授权的 AI 完成；核心规则变化或原验收结论失效时，相关系统项需重新验收。

## 系统功能验收清单

- [ ] **石头关卡**：客户端自动攻击、维护个人血量并表现击破和秒杀穿行；服务端按玩家和轮次在首次进入区域时预生成普通、幸运及空石头内容；离开后重进不补充，击破只揭露已定内容；回基地边沿结束本轮并恢复个人石头，角色更换只恢复满血石头与已击破快照，不重抽；无效命中撤销本地扣血。入口：[客户端石头组件](../StarterPlayer/StarterPlayerScripts/Client/Player/CRockLevelCompClass.lua)、[服务端石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.lua)。
- [ ] **等级与训练**：走路和有效击打获得训练值并升级；点击不增加实际收益；主界面正确显示等级、力量和经验，重登恢复训练进度。入口：[杂项组件](../ServerScriptService/Server/Player/SMiscCompClass.lua)、[主界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CMainUICompClass.lua)。
- [ ] **道具与背包**：出生与重生获得镐子；区域预生成的收藏品按 `ItemData[itemId].DisplayModelId` 取模型，仅拥有者可拾取，未拾取掉落超时消失；服务器记录唯一掉落 ID、道具 ID、价格及幸运信息，拒绝伪造、过期及重复拾取；战利品可查看并在回基地后转入正式背包，满包不丢失、不重复领取；收藏品可装备，重生与重登后名称、价格、幸运倍率和库存正确恢复，旧存档无幸运字段时按普通道具处理。入口：[石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.lua)、[收藏品适配](../ServerScriptService/Server/Player/RockCollectible.lua)、[背包适配](../ServerScriptService/Server/Player/SPlayerObjectClass.lua)。
- [ ] **钻石**：主界面正确显示余额，重登保持存档余额。入口：[主界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CMainUICompClass.lua)。
- [ ] **重生**：主界面打开重生预览，达标后服务端将经验归零、等级重置为 1 并增加一次重生；未达标、重复请求和达到版本上限不结算，货币与背包保留，重登恢复次数及进度。入口：[重生界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CRebirthUICompClass.lua)、[服务端结算](../ServerScriptService/Server/Player/SMiscCompClass.lua)。
- [ ] **本地化**：项目只维护英文；收藏品名称、品质、幸运掉落与拾取提示使用稳定 Key 和英文兜底；其他语言读取 Roblox 云端译文，缺失时使用本地英文；语言切换刷新当前掉落文案。新增动态 Key 是否已导入 Roblox 云端翻译表仍需确认。入口：[翻译模块](../StarterPlayer/StarterPlayerScripts/Client/Localization.lua)、[文案表](../ReplicatedStorage/Scripts/Game/Shared/Localization.csv)。

## 数值验收清单

- [ ] **石头关卡**：13 关血量、推荐等级、攻击力与等级差减伤符合[关卡配置与公式](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.lua)；普通攻击间隔 0.8 秒，伤害达到满血秒杀条件时每 0.1 秒最多击破一块。
- [ ] **等级与训练**：初始 1 级、最终上限 780，每阶段等级封顶于当前重生门槛，经验最多填满该等级；升级需求与累计经验符合[等级曲线配置](../ReplicatedStorage/Scripts/Game/Configs/NumericalConfig.lua)；每秒走路基础 +2、有效击打基础 +2，同时成立基础 +4，按重生倍率及追赶规则结算，点击不叠加收益。
- [ ] **重生**：首次门槛 15 级，每次增加 15 级，最多 51 次；训练和金币倍率按原配置为 `1 + 2 × 重生次数`，追赶额外经验仅补至上一次重生门槛，倍率沿用原曲线。金币倍率已用于预览，金币收益系统尚未接入。依据：[重生公式](../ReplicatedStorage/Scripts/Game/Shared/Rebirth.lua)、[数值配置](../ReplicatedStorage/Scripts/Game/Configs/NumericalConfig.lua)。
- [ ] **道具与背包**：世界 1 每个已配置区域每轮预生成 4 件普通与 3 件幸运内容，分别占据不同格子；奖池按 `AreaRefreshData.RewardPool` 权重抽取，普通价为 `ItemData.Pirce`，幸运价为基础价乘 `LuckRefreshRate` 抽取的 2.5～3 倍；区域未命中格为空且不补抽，幸运状态和倍率随战利品及背包保留；未拾取掉落从服务器生成起 10 秒后消失；战利品容量 3 件，正式背包总容量 12 格，快捷栏与背包共用容量，收藏品每格 1 件、不堆叠；拾取后战利品与正式背包已占用格数合计不得超过 12，超限拒绝拾取并提示，地上道具保留至超时；拾取与入库不直接增加货币。依据：[GameConfig](../ReplicatedStorage/Shared/Config/GameConfig.lua)、[收藏品参数](../ServerScriptService/Server/Player/RockCollectible.lua)、[关卡配置](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.lua)、[背包容量配置](../ReplicatedStorage/Scripts/SetupProvider.lua)。
- [ ] **钻石**：新玩家初始 500，已有存档余额不重置。依据：[玩家数据配置](../ReplicatedStorage/Scripts/Game/Shared/PlayerDataConfig.lua)。
