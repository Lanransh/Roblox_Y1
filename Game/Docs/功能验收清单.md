# 功能验收清单

仅记录当前已实现玩法，以玩法系统为整体验收单位。勾选表示验收通过，只能由用户或用户明确授权的 AI 勾选；改动影响玩法行为或数值结果后，受影响项自动取消勾选，需重新验收。纯框架整理、日志等不影响玩法的改动不列项。

## 系统功能验收清单

- [ ] 测试道具与原生背包：默认开启时，Studio 空背包发放测试道具，玩家可通过原生背包选择并使用；`FrameworkConfig.NativeBackpack.ShortcutEnabled = false` 时不生成框架手持 Tool，客户端不绑定手持输入，服务端拒绝 ActivateTool；道具数据、发放和服务端直接 UseItem 保留。InventoryEnabled 控制原生界面显示；任一字段为 false 时同时隐藏原生快捷栏及背包面板，只关闭面板时输出限制警告。原生界面无法独立隐藏其中一个。入口：`ReplicatedStorage/Scripts/Framework/FClient.lua`、`ReplicatedStorage/Scripts/Framework/Client/FCNativeBackpack.lua` 和 `ServerScriptService/Server/Player/SPlayerObjectClass.lua`。配置及手持控制调整，待试玩验收。
