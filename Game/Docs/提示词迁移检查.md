## 关键差异已处理

- 本地 `Game/` 是 Rojo 项目根，运行时没有 Game 前缀；Git 位于上级仓库，Tests、Tools、Build 已统一移入 Game，不加入服务映射。当前 `Game/Shared/` 未映射到服务，公共新代码应放 `ReplicatedStorage/Shared/`。
- 项目协议放 `FrameworkConfig.ClientMessages/ServerMessages`，框架协议放 `FrameworkInit.lua`。Provider 在网络初始化时提供项目协议，不使用不存在的 NetworkProtocol.lua，也不在初始化后临时追加白名单。
- 玩家字段使用 `FrameworkConfig.PlayerData`；表数据修改后需 SetTable。同步默认值回放、每秒组件更新、显式注册类与资源清理按源码说明。
- 网络回调 userId 由引擎身份确定，客户端仍需校验数量、目标、实例归属与状态。服务端全局协议只注册一次。
- UI 模板在 StarterGui，实际界面在 PlayerGui；ScreenGui 使用 Enabled，GuiObject 使用 Visible；复制、重生与动态销毁需要按生命周期处理。
- Developer Product 入口为 `FCCommonUIComp:ShowDeveloperBuyUI(productId)`；凭证结算由唯一 FSShopService.ProcessReceipt 完成，不沿用 MiniStudio DeveloperStoreService 或旧多参数入口。
- 保留默认不启动游戏的验证习惯；用户明确要求测试或试玩时按授权执行。编译、构建、替身测试和真实平台验收必须分别说明，不复用历史结果冒充本次验证。
- 开发资料没有加入 Rojo 服务映射。

## 当前尚未实现的功能边界

这些是当前项目能力差异，已在相关参考中说明，不是本次遗漏的提示词适配：

- **自定义背包**：当前使用服务端 Tool 和 Roblox 默认 Backpack；没有 FCInventoryCompClass、定制筛选/详情/拖拽 UI。Inventory 当前 Sync=false，不能照抄完整客户端背包数据接法。
- **触摸与拖拽类**：没有 FCTouchObjectClass、FCDragObjectClass。参考改为 Activated 与原生输入生命周期，不创建替代框架。
- **Timeline**：没有 FXTimelinePlayer/Track/Clip；参考改为现有 UIAnim、模型动画及 TweenService 的按需选择。
- **好友倍率**：已有服务器验证的好友状态与同服人数；没有收益倍率配置、对应货币字段或邀请界面。倍率公式、上限和应用范围须由实际需求确定。
- **商店、排行榜、引导、声音**：有基类，但当前 Goods/Rankings/GuideGroups 为空，项目也没有挂载完整业务界面、客户端引导表现或声音组件。参考不能声称示例节点和字段已经存在。
- **奖励类型**：当前通用奖励支持 Item/Money，Money 依赖明确的货币字段映射；不假设 Pet/Jade/Gem 等原玩法奖励已迁入。
