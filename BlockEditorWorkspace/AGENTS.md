## 方块模型工作区

本工作区使用 `block-model-editor` MCP 制作、编辑和检查方块模型。
开始在本工作区工作时，先调用 `bme.docs.read({ "files": ["AGENTS.md"] })`，
读取工具指南与可用技能摘要，再按任务读取相关 skill 和参考文档；已有必要说明时可复用。
模型修改通过 MCP 完成，不手写工程 JSON。操作前确认当前工作区、模式和 revision，
并继续遵守所属项目规则与用户授权；读取文档不授予保存、覆盖、删除或导出权限。
