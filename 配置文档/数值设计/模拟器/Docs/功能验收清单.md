## 训练、力量与等级

- [ ] 训练与闯关均按配置频率结算训练值，升级后按等级更新力量；训练模式额外应用场地倍率。入口：模式切换、`Code/State.ts`。待重新验收：力量改为第 1 级至当前等级（含当前等级）的升级需求之和。
- [ ] 自动升级只扣剩余训练值，保留溢出经验，按新等级重算力量；同级训练和满级后力量不变。入口：`State.advanceOneSecond()`。待重新验收：新版等级求和力量。
- [ ] 镰刀、光环、重生奖励、追赶、付费倍率和道具收集倍率共同影响训练收益。入口：`State.getTrainingValuePerSettlement()`；待验收。

## 关卡与金币

- [ ] 重生次数决定可挑战末关与世界；每轮从当前世界首关逐关前进。入口：闯关模式、`State.getHighestChallengeStageId()`；待验收。
- [ ] 关卡血量等于第 1 级至期望等级（包含该等级）的升级需求之和乘血量倍率并取整；起始基准为 1，血量至少为 1。入口：`Formulas.calculateStageCombatValues()`。待重新验收：血量倍率改为 2.5。
- [ ] 力量达到血量时使用快速耗时，否则使用普通耗时；闯关中继续训练并逐秒重新判断。入口：`State.getCurrentPhaseDuration()`。待重新验收：判断输入变更。
- [ ] 末关按配置间隔采集，背包装满返家出售，取得金币后重新出发。入口：`State.advanceChallengeOneSecond()`。待重新验收：血量变化影响出发耗时。

## 装备与自动模式

- [ ] 金币购买下一档镰刀或光环，价格由期望关卡、重生金币倍率和期望道具数量派生；不足或满级时阻止购买。入口：镰刀/光环升级按钮、`Code/Actions.ts`；待验收。
- [ ] 自动模式购买当前阶段可负担装备，缺金币时闯关，否则训练；满足重生门槛时执行重生。入口：自动模式开关、`Game.advanceOneSecond()`。待重新验收：新血量改变刷金币耗时，完整自动成长尚未复验。

## 重生与回级

- [ ] 重生受等级与次数上限限制；成功后等级回到 1，训练值清零，力量按 1 级公式变为 1，金币及装备保留。入口：重生按钮、`RebirthAction`。待重新验收：力量重置规则变更。
- [ ] 重生后在追回本次门槛等级前应用追赶倍率，并按重生次数选择场地。入口：重生卡片、`State.getCurrentRebirthField()`；待验收。
- [ ] 重生前及回级完成时创建项目回退点，并记录回级耗时。入口：`RebirthAction`、`CompleteRebirthRecoveryAction`。待重新验收：还原状态中的力量语义变更。

## 钻石与付费模拟

- [ ] 按配置逻辑日赠送钻石，小/大周卡分别保存每日奖励进度。入口：周卡按钮、`State.advanceOneSecond()`；待验收。
- [ ] 付费训练倍率可钻石或模拟付费逐档提升，背包可逐档扩容，均遵守上限。入口：付费倍率/背包卡片；待验收。
- [ ] 钻石自动提升倍率与自动扩容可独立开关，优先倍率，再购买可负担的扩容。入口：钻石自动按钮、`Game.advanceAutoDiamondUpgrades()`；待验收。
