### 新建玩家

- [x] **验收完成**

---

> 开局钻石 = 新手赠送 + 非负向下取整（首日每日赠送）

- 新建时同时发放新手与首日奖励，赠钻计时从空进度开始；下一次每日奖励须等满一个逻辑日。
- 初始付费倍率为免费基础档。默认开启的钻石自动提升会按价格购买下一档，不再直接赠送已购档位。
- 起始镰刀、起始等级由构造函数指定；光环未解锁，重生、训练值、扩容与背包均为空进度，力量与累计训练值均为空进度。

初始金币：`config: 初始金币`。<br>
新手钻石：`config: 新手赠送钻石`，直接加到账户。<br>
首日奖励：`config: 每日赠送钻石数量`，先向下取整并限制为非负。<br>
初始档位与开关：代码固定值，来自 `State.constructor()`；力量规则见[等级力量](#等级力量)。

实现来源：[State.ts](../Code/State.ts) 的 `constructor()`。

### 保存与恢复

- [x] **验收完成**

---

- 保存资源、装备、等级与训练值、重生与回级进度、全部自动开关、赠钻及周卡计时、付费与扩容档位、闯关位置及背包数量。
- 恢复时以累计训练值派生等级与力量，忽略新版存档中的等级和力量字段；已保存的钻石直接恢复，不再次发放开局奖励。
- 缺省与规范化按下表处理；训练值规范化到起点与满级累计门槛之间；上一版未标记的本级剩余值按已保存等级的累计门槛转换。其余模式及闯关字段直接读取，没有通用历史格式迁移或损坏数据修复。

| 字段类别 | 缺失或恢复时的处理 |
| --- | --- |
| 金币、钻石 | 分别回退到初始金币、新手钻石配置；钻石缺失时不另补首日奖励 |
| 镰刀、光环、重生、扩容 | 镰刀回退到起始装备，其余回退到空进度 |
| 主自动、钻石自动开关 | 主自动缺失时开启；两种钻石自动开关仅在存档明确为开启时开启 |
| 回级、赠钻计时 | 回级字段缺失表示无任务，赠钻计时缺失用空进度 |
| 周卡次数、计时 | 次数取非负整数且不超过购买当天之后的剩余次数上限；计时取非负整数 |
| 付费倍率档位 | 取非负整数并限制到代码开放上限；缺失时为免费基础档 |

**配置来源**

资源回退：`config: 初始金币`、`config: 新手赠送钻石`。<br>
累计门槛：`config: 等级曲线.升到下一级所需经验`，累加目标等级之前各级需求；新快照的训练值带累计量标记，旧版剩余值转换使用保存等级。<br>
恢复上限：代码固定值，周卡奖励天数与付费倍率开放上限分别由 `Formulas.ts` 的 `WEEKLY_CARD_REWARD_DAYS`、`MAX_PAID_MULTIPLIER_ID` 定义。

实现来源：[State.ts](../Code/State.ts) 的 `toJSON()`、`loadJSON()`。

## 训练、等级与力量

---

曲线取值约定（本系统与后文共用）：

- 公共输入先按各曲线组的输入取整方式向下取整，再校验有限整数与输入上下限的闭区间；越界报错。两端均未配置时，负输入归到非负起点。
- 完整组按列顺序采样，列未指定输入时沿用公共输入；指定前列时使用前列结果。独立列公式采样直接使用传入参数，不执行前列依赖。
- 每列使用自身公式及其结果取整方式。分段参数在段内插值，首段前取起值、缺口延续前段末值、末段后取末值；算法见 [CommonApi.md](../Api/CommonApi.md)。

### 训练收益

- [x] **验收完成**

---

> 基础训练值 = 镰刀训练值 × 光环倍率 × 当前重生训练奖励
>
> 单次训练值 = 基础训练值 × 追赶倍率 × 模式场地倍率 × 付费训练倍率 × 道具收集倍率

- 训练与闯关都获得训练值；只有训练模式享受场地倍率，闯关使用中性场地倍率。
- 每秒按配置次数逐次结算，频率不会因为切换模式而改变。
- 每次增加累计训练值，再按累计门槛派生等级；同秒的后续训练重新判断追赶条件。满级时不再结算训练，最后一次收益仅计入距满级门槛的差值。
- 各项按自身曲线取整，最终乘积不再统一取整。新装备、重生与付费档位替换旧档效果，不累乘历史档位。

**配置来源**

结算次数：`config: 每秒训练次数`；直接作为整次循环的上限，正小数形成向上取整的循环次数，非正值不训练。<br>
镰刀训练值：`config: 镰刀曲线组.镰刀训练值倍率`；当前镰刀 ID 输入，幂曲线，向上取整。<br>
光环倍率：`config: 光环曲线组.光环倍率`；已解锁时按当前 ID 采样幂曲线，不取整；未解锁时使用代码中性倍率。<br>
重生训练奖励：`config: 重生曲线组.重生训练倍率奖励`；当前已完成重生次数输入，幂曲线，不取整。<br>
其他乘区：见[追赶倍率](#追赶倍率)、[训练场地](#训练场地)、[倍率升级](#倍率升级)、[收集加成](#收集加成)。

实现来源：[State.ts](../Code/State.ts) 的 `getTotalTrainingMultiplier()`；[Formulas.ts](../Code/Formulas.ts) 的装备与重生取值函数。

**当前备注**

待重新验收：累计训练值与力量统一，等级由累计门槛派生，满级停止增长；本节及关联展示或结算受影响。

待重新验收：初始付费档位与自动购买价格改变，影响早期训练收益。

### 收集加成

- [x] **验收完成**

---

> 解锁道具数 = 最高可挑战关卡编号 × 非负向下取整（每关解锁道具数）
>
> 收集倍率 = 中性倍率 + 解锁道具数 × 单件训练加成系数

- 按重生准入后的最高关卡估算，不要求实际通关或拾取。
- 重复采集不会累计加成；背包数量不参与计算。没有可挑战关卡时使用中性倍率。
- 加成只进入两种模式的训练收益，不进入出售金币公式。

**配置来源**

每关数量：`config: 每关解锁道具数`。<br>
解锁关卡：见[关卡准入](#关卡准入)。<br>
中性倍率与单件系数：代码固定值，来自 `getItemCollectionMultiplier()`。

实现来源：[State.ts](../Code/State.ts) 的 `getUnlockedItemCount()`、`getItemCollectionMultiplier()`。

### 自动升级

- [x] **验收完成**

---

> 升级需求 = 四舍五入（需求基数 + 当前等级 ^ 需求指数 × 需求乘数）
>
> 达到目标等级的累计门槛 = 起始等级至目标等级前一级的升级需求之和
>
> 当前等级 = 累计训练值已达到门槛的最高等级

- 等级从累计训练值反查，达到门槛的等号也计为升级；一次训练可以跨越多个等级，升级不扣除累计训练值。
- 每级需求仍以该级等级为输入采样；达到目标等级只累加此前各级需求，不包含目标等级自身需求。
- 累计训练值上限为达到满级所需的总量，满级自身的下一等级需求不计入上限；最后一次训练超出部分不计入，满级后训练值与力量都停止增长。

**配置来源**

升级需求：`config: 等级曲线.升到下一级所需经验 → 公式`；幂曲线，指数按当前等级命中分段，结果四舍五入。<br>
需求参数：`config: 等级曲线.升到下一级所需经验 → 公式参数`，分别使用基数、指数与乘数。<br>
等级范围：`config: 等级曲线 → 输入上下限`，包含两端。

实现来源：[State.ts](../Code/State.ts) 的 `level`、`advanceOneSecond()`；[Formulas.ts](../Code/Formulas.ts) 的 `calculateTrainingLevel()`、`calculateLevelStrength()`。

**当前备注**

待重新验收：累计训练值与力量统一，等级由累计门槛派生，满级停止增长；本节及关联展示或结算受影响。

### 等级力量

- [x] **验收完成**

---

> 当前力量 = 本轮累计训练值
>
> 训练值上限 = 起始等级至满级前一级的升级需求之和

- 力量直接读取累计训练值，不独立保存第二份可变状态；升级只改变派生等级，不扣除训练值。
- 同级训练也增加力量；新建与重生时训练值、力量均为空进度。
- 满级所需总量逐级独立采样升级需求列，各项先取整再相加，不含满级自身需求；达到上限后两者都不再增加。
- 闯关直接用力量与最终草血量比较，没有独立的攻击力状态或逐秒扣血伤害。

**配置来源**

满级门槛：`config: 等级曲线.升到下一级所需经验`，满级之前每个求和等级直接作为独立列公式输入。<br>
求和起点：`config: 等级曲线 → 等级下限`，缺失时使用函数内起始等级；目标等级先经曲线校验。

实现来源：[Formulas.ts](../Code/Formulas.ts) 的 `calculateLevelStrength()`；[State.ts](../Code/State.ts) 的 `strength`、`trainingValue`、`advanceOneSecond()`。

**当前备注**

### 装备定价

- [x] **验收完成**

---

> 目标关卡 = 非负向下取整（目标装备的期望关卡）
>
> 定价重生次数 = 非负向下取整（目标关卡的期望重生次数）
>
> 购买价格 = 向下取整（非负目标关卡单价 × 定价重生金币倍率 × 非负向下取整后的期望道具数）

- 购买查询以紧邻下一装备 ID 为输入，先取期望关卡和数量，再取该关单价、该关期望重生次数对应的金币倍率。
- 定价使用配置期望的重生次数，不使用玩家实际重生次数；金币倍率不另做非负限制。
- 目标关卡为空起点时价格为空成本，但实现仍先完成关卡与重生曲线查询。未解锁光环自身的缺省查询不代表首次购买免费。

**配置来源**

镰刀期望：`config: 镰刀曲线组.期望关卡`、`config: 镰刀曲线组.期望道具数量`；目标镰刀 ID 输入，两列均为幂曲线并向下取整。<br>
光环期望：`config: 光环曲线组.期望关卡`、`config: 光环曲线组.期望拾取数量`；目标光环 ID 输入，取整同镰刀。<br>
关卡单价：`config: 关卡曲线组.期望道具价格`；目标关卡输入，指数曲线，向下取整。<br>
定价重生次数：`config: 关卡曲线组.期望重生次数`；目标关卡输入，幂曲线，向下取整后限制非负。<br>
定价金币倍率：`config: 重生曲线组.重生金钱倍率奖励`；定价重生次数输入，幂曲线，不取整。

实现来源：[Formulas.ts](../Code/Formulas.ts) 的 `calculateSickleValues()`、`calculateAuraValues()`。

### 手动购买限制

- [x] **验收完成**

---

- 点击镰刀或光环升级按钮，只购买紧邻下一等级；首次购买光环从未解锁变为首个可购买等级。
- 先检查满级，再检查金币。余额不足或已满级时不扣款、不升级；恰好足够时允许购买。
- 成功扣除[派生价格](#装备定价)，对应装备提升一级，后续训练使用新档效果。
- 手动购买不检查重生门槛；主自动开启时装备按钮仍按上述条件启用。

**配置来源**

等级上限：`config: 镰刀曲线组 → 镰刀 ID 上限`、`config: 光环曲线组 → 光环 ID 上限`。<br>
下一档查询：镰刀查询限制到自身上限；光环查询不夹取，由购买检查先阻止满级后的下一档采样。

实现来源：[Actions.ts](../Code/Actions.ts) 的 `UpgradeSickleAction`、`UpgradeAuraAction`；[Game.ts](../Code/Game.ts) 的装备按钮。

### 关卡准入

- [x] **验收完成**

---

> 目标末关 = 总关数内，期望重生次数不高于玩家重生次数的最大关卡 ID

- 从总关数向前逐关查询门槛；等级和力量不参与准入。门槛采样后向下取整并限制为非负。
- 没有符合门槛的关卡时，不能切入闯关；已经在闯关时，下次推进退回训练。
- 界面在无目标时仍按首关显示兜底信息，不表示首关已解锁。

**配置来源**

总关数：`config: 关卡曲线组 → 展示采样上限`；仅曲线展示时读取，缺失用首关，再向下取整且至少保留一关。<br>
准入门槛：`config: 关卡曲线组.期望重生次数`；扫描关卡 ID 输入，幂曲线，向下取整。

实现来源：[State.ts](../Code/State.ts) 的 `getStageCount()`、`getHighestChallengeStageId()`；[Actions.ts](../Code/Actions.ts) 的 `SwitchModeAction`。

### 世界路线

- [x] **验收完成**

---

> 目标世界 = 向上取整（目标末关 / 每世界关数）
>
> 世界内末关 = （目标末关 − 首关编号）对每世界关数取余，再平移回首关编号
>
> 当前全局关卡 = （当前世界 − 起始世界编号）× 每世界关数 + 世界内关卡

- 每轮从目标世界首关出发，顺序走到末关，不从全局首关重走之前世界。
- 每次进入闯关都重开一轮，清空阶段时间与背包，阶段设为出发；切回训练只暂停推进，再次进入仍重新开始。
- 目标世界改变或当前位置超过新目标时，重开一轮并结束当秒闯关推进。
- 重复切到同模式会被阻止。主自动开启时，手动模式按钮禁用。

**配置来源**

每世界关数：`config: 世界关卡数`，向下取整且至少保留一关。<br>
路线目标：见[关卡准入](#关卡准入)；无目标时世界和末关展示使用首关兜底。

实现来源：[State.ts](../Code/State.ts) 的 `getChallengeWorld()`、`getChallengeLastStage()`、`startChallengeRun()`、`switchMode()`。

<br>

### 草血量

- [x] **验收完成**

---

> 期望力量 = 起始力量基准，当期望等级不高于起始等级；否则为该期望等级的等级力量
>
> 草血量 = 至少为最小有效血量的向下取整（期望力量 × 血量倍率）

- 以全局关卡 ID 采样完整关卡组，先算期望重生次数，再以该列结果计算期望等级。
- 期望等级使用幂曲线并向下取整；它不是直接按关卡 ID 计算，也不参与准入或装备定价。
- 期望力量取刚达到期望等级所需的累计训练值，只累加此前各级需求；期望等级越过等级曲线边界会报错，不自动替换成满级。
- 快速通关比较最终草血量，不只比较计算血量用的期望力量。

**配置来源**

期望等级：`config: 关卡曲线组.血量计算等级`，列输入引用 `config: 关卡曲线组.期望重生次数`；公式参数取该列自身公式。<br>

### 重生条件与重置

- [x] **验收完成**

---

- 点击重生或由自动模式触发时，先检查次数上限，再检查等级达到下一次门槛；不满足时不改状态。
- 门槛按重生前已完成次数采样，不先增加次数。训练、金币奖励也按当前已完成次数取当前档，替换旧档效果。
- 成功保存本次门槛与当前 tick 为回级目标和起点，再增加重生次数、回到起始等级、清空累计训练值与力量并切回训练。
- 金币、钻石、装备、付费与扩容档位、周卡、计时及自动开关保留；不重新发开局钻石。
- 闯关进度与背包字段不在重生方法中清空，下次进入闯关时统一重开。

训练奖励：`config: 重生曲线组.重生训练倍率奖励`；当前次数输入，幂曲线，不取整。<br>
金币奖励：`config: 重生曲线组.重生金钱倍率奖励`；当前次数输入，幂曲线，不取整。<br>
重置：`applyRebirth()` 清空累计训练值，等级从累计门槛反查为起始等级；力量见[等级力量](#等级力量)。

### 追赶倍率

- [x] **验收完成**

---

> 追赶截止等级 = 上一次重生前的已完成次数所对应的要求等级
>
> 当前追赶倍率 = 已重生且当前等级低于截止等级时取当前档追赶配置，否则取中性倍率

- 截止等级使用当前次数减去一次，并限制到非负起点；追赶配置使用当前次数，两者索引不同。
- 达到截止等级时立即停止加成，不等待回级完成 Action。
- 两种模式的训练都使用此条件，不依赖保存的回级任务是否为空。

**配置来源**

截止等级：`config: 重生曲线组.重生要求等级`，上一次数输入。<br>
追赶配置：`config: 重生曲线组.重生追赶倍率`，当前次数输入，幂曲线、分段乘数、向上取整。<br>
中性倍率：代码固定值，来自 `calculateRebirthCatchUpMultiplier()` 的缺省分支。

实现来源：[State.ts](../Code/State.ts) 的 `getPreviousRebirthRequiredLevel()`；[Formulas.ts](../Code/Formulas.ts) 的 `calculateRebirthCatchUpMultiplier()`。

### 训练场地

- [x] **验收完成**

---

- 没有解锁场地时使用中性倍率；有场地时自动选择，无需购买或手动切换。

### 回级计时与回退点

- [x] **验收完成**

> 回级耗时 = 非负向下取整（完成时 tick − 重生时 tick）

- 重生前有编辑器上下文时，先建立“重生”回退点并记录实际等级，再执行重生。

### 每日赠钻

- [x] **验收完成**

---

> 逻辑日秒数 = 至少一次秒级推进的向上取整（逻辑日小时数 × 每小时秒数）
