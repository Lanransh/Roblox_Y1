# 资源与节点工作流

## 原始素材与同步对象

`ArtSource` 保存 OBJ、FBX、贴图和音频源文件；`Game` 保存需要同步进 Roblox 的对象，包括脚本、模型、UI 和场景节点。
所有路径以下均以仓库根目录为基准。

## OBJ / FBX

1. 源文件、MTL 和贴图放在 `ArtSource/Models/资源名/`。
2. 使用 Studio 导入器导入，检查尺寸、朝向、贴图、碰撞和资源权限，按需上传到 Roblox。
3. 将 Roblox 模型导出为 `.rbxm` 或 `.rbxmx`。
4. 公共模板放 `Game/ReplicatedStorage/Assets/Models`，场景里的固定模型放 `Game/Workspace`，地图模板放 `Game/ServerStorage/Assets/Maps`。

Rojo 不直接转换或上传 OBJ、FBX。模型文件中的云端网格、贴图引用仍需有效资源 ID 和使用权限。
Rojo 官方列出 MeshPart.MeshId、Terrain、CSG 等实时同步限制。遇到网格不能正确同步时，可在 Studio 中维护该对象，或使用 Rojo 构建的场景文件检查。

## 图片 / 音频 / 动画

原始图片和音频放在 `ArtSource/Images`、`ArtSource/Audio`。
上传或发布后，在 `Game/ReplicatedStorage/Shared/Config/AssetIds.lua` 填写真实资源 ID。

## UI / 特效 / 地图

- 默认随玩家生成的 ScreenGui 放在 `Game/StarterGui`。
- 动态创建的 UI 模板放在 `Game/ReplicatedStorage/Assets/UI`。
- 特效模板放在 `Game/ReplicatedStorage/Assets/Effects`。
- 地图模板放在 `Game/ServerStorage/Assets/Maps`，由服务端克隆到 Workspace。
- 固定场景节点放在 `Game/Workspace`。
- 在 Studio 中维护的完整场景和 Terrain，可以保存到 `Places`，不会自动包含在 Rojo 构建里。

## 简单节点

可以用 `.model.json` 描述简单对象。例如需要一个交互事件时，可创建 `Game/ReplicatedStorage/Interact.model.json`：

```json
{
  "ClassName": "RemoteEvent"
}
```

它会生成 `ReplicatedStorage/Interact`，类型是 RemoteEvent。该例仅说明文件格式，项目当前没有创建此事件。
普通目录默认是 Folder；需要将目录变成 Model、ScreenGui 等类型时，在目录中添加 `init.meta.json`，例如 `{ "className": "Model" }`。

通过 Studio 修改本地管理的资源后，需要主动导出回相应文件。普通 serve 不会自动回写。
