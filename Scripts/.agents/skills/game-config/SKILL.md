# 游戏配置

本技能描述跨游戏复用的配置分类与组织规则。具体游戏有哪些子表、字段和业务处理器，以当前工程工作簿与消费代码为准。

使用 `sgtk.config` 的脚本执行接口（`sgtk.config.execute_script`）查询和修改配置；接口用法以 MCP 工具说明为准，本 skill 不重复维护。

需要判断配置归属、组织五类配置或选择通用字段与独立子表时，读取 [配置分类与组织](references/game-configs.md)。

## 安全与接入约束

- 修改前读取目标配置声明、Meta、字段、主键和记录，不依赖固定路径或预设子表。参考文档中的名称和数值只是示例，不自动要求新增。
- 生成的 Lua/Luau 配置仅可只读；变更必须通过 MCP 修改原始 XLSX，检查并保存成功后再导出，不直接修补 XLSX 或生成文件。
- 检查或保存失败时保留草稿；发生冲突不擅自覆盖或丢弃修改。MCP 不可用或无法修复时报告具体阻断，不绕过流程。
- 分类决定数据职责；Meta 决定导出结构；消费代码决定业务字段含义。新增业务字段或处理器时，核对游戏侧接入。
- 只读说明无需保存或导出。修改后区分草稿、已保存、已导出和游戏验证状态；遇占用、版本冲突或不支持格式时报告实际阻断。
