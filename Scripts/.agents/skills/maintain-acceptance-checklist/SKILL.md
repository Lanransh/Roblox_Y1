# 系统验收清单

- 先读 `Docs/功能验收清单.md`，只核对受影响系统。保留“系统功能验收清单”和“数值验收清单”两部分，每个已实现系统原则上各一项，记录关键功能与核心数值。
- 系统增删或核心规则变化时更新原项；普通修复、表现细节和开发验证不记入清单，也不自动取消勾选。整理时合并零散项，移除修改日志和未实现功能。
- 核心规则变化或原验收结论失效时，仅将受影响项改回 `- [ ]`。预期依据用户要求或已确认设计，不以现有实现自行认定正确。
- 新系统默认 `- [ ]`；只有用户亲自勾选，或明确授权 AI 勾选指定项时，才使用 `- [x]`。
- 记录验收结论时写简短结果，证据与日期按需附上。部分通过不等于整体通过，编译成功和文档整理不代表实际验收。
