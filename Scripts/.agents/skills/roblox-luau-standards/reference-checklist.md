# Luau 自检

- 函数注释与形参、实际返回值一致，说明业务原因或约束。
- 保持现有风格；没有顺手重构、额外抽象或无需求的功能。
- 配置只读取目标片段，必填字段没有静默默认值。
- Roblox 服务和节点 API 有源码或官方文档依据。
- 固定节点路径已核对，复制等待和动态节点缺失按生命周期处理。
- 框架初始化后的必需固定路径加载优先使用 `FX.Loader`；仍使用原生等待的代码有初始化时序或等待语义依据，替换没有改变超时与缺失处理约定。
- 协议参数在服务端验证；可信内部调用没有重复容错。
- 新增模块显式 require、返回有效结果；用到的 FX/FC/FS 从 _G 显式取值。
- 连接、任务、实例及网络回调有对应清理。
- 验证结果区分语法、Rojo 构建与实际运行；没有把历史测试当成本次结果。
