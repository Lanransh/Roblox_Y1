## 翻译文本收集工具的配置字段

请在工具中勾选：

| 配置 | 字段 | 显示位置 |
| --- | --- | --- |
| GameConfig.ToolConfig | Name | 武器商店及背包工具名 |
| GameConfig.AuraConfig | Name | 光环商店、菜单奖励 |
| ItemConfig.Display | Name | 福利、周卡商店、背包道具名 |
| ItemConfig.Display | Desc | 背包道具说明 |

`GameEnum.WorldTransferConfig.Name` 是手写共享定义，不是生成 XLSX 配置字段；World 1/2/3 已由共享 Mark 原文覆盖。

暂不以 `GameConfig.ItemData.Name` 替换拾取物名称：该字段存在中文、重复值及与 DisplayModelId 不符的内容，缺乏可信英文源。保留模型编号对应的已有英文来源，禁止把模型路径或编号当作显示名称翻译。

## 剩余问题与不确定项

- `Main.GoHome` 在当前英文 CSV 中没有来源，仍保留旧 Key 兼容查询，不能宣称已覆盖。Tutorial.Login/Collected/Deposited 等是流程事件标识，不属于待翻译显示文字。
- 已从实际引导步骤和排行榜显示用途确定 `Tutorial.AutomaticTraining`、`Tutorial.Rewards`、`Leaderboard.PlaytimeLabel` 的英文建议，并在共享源中加入 Mark；需要重新运行收集工具后才会出现在收集结果中。
- 工具配置名称如 WornWoodenPickaxe、道具名 DogCard 属于内部式英文拼写，本次按配置原值翻译，不擅自修改源配置。正式英文与配置内容需通过配置工具另行确认。
- Studio 连接在初次 Edit 状态读取后中断，未能核对同步内容、脚本类型、RunContext、StarterGui 模板和场景固定文字。因此不能宣称全场景所有玩家可见文字已覆盖；模板固定标题仍可能依赖 ATC。
- GM 是开发者调试界面，其中文调试提示及 ShowTips 保持原样。
- 本次未运行收集导出、上传云端、重建现有翻译表或启动试玩。330 个 Mark 定义不代表已经收集或已有目标语言译文。
