# 道具说明框视觉设计稿

## 视觉方向

暖深棕游戏 HUD 卡片，搭配柔和米金边框，呼应明亮、偏暖的游戏场景。外轮廓明确，文字厚实；雾光仅在卡片内部形成柔和层次。
延续左图标、右名称与描述的结构，固定在力量栏下方。

## 布局

以主界面设计坐标计，卡片宽度按名称、描述的实际文字宽度计算，限制在 220～420；最小高度 72，长描述换行后向下撑高。
每次道具切换或语言刷新重新计算，不保留上一件道具的尺寸。
与力量栏间隔 10，卡片居中。圆角 12。
图标 48 × 48，距左 12、距上 12；文字从左 72、上 10 开始。
文字区右侧留白 16，标题与描述间隔 4，底部留白 12。
无图标的道具，文字从左 16 开始。

## 色彩和边框

| 元素 | 规格 |
| --- | --- |
| 背景 | 暖深棕 RGB(48, 38, 30)，透明度 0.22 |
| 边框外轮廓 | 深棕黑 RGB(23, 17, 12)，厚 3 |
| 主边框 | 柔和米金 RGB(209, 182, 130)，厚 2，透明度 0.18 |
| 内部雾光 | 暖琥珀 RGB(144, 109, 66)，弱透明叠层，向两端渐淡 |
| 标题 | 暖白 RGB(255, 243, 215) |
| 描述 | 米白 RGB(250, 247, 237) |

背景不再向两侧完全消失，保证边框闭合、轮廓完整。
雾光保留在内部，不以模糊文字或全屏景深表现雾感。

## 字体

- 标题：GothamBlack，26 号，2 像素深棕黑实色描边。
- 描述：GothamBold，22 号，1.5 像素深棕黑实色描边。
- 禁用自动缩字；标题和描述都允许换行，按实际高度纵向排列。
- 字体和卡片整体随现有主界面分组适配屏幕。

## 实现与核对范围

仅调整 ToolDescription 展示模块，不改道具数据、文案、装备监听或使用逻辑。
核对边框不受内部雾光渐变影响，文字使用明确的 Contextual 描边。
完成 Luau 编译、git diff --check，以及 Studio 同步内容核对。
运行时观感和长文本布局需在实际试玩中验收，静态检查不代表视觉验收。
