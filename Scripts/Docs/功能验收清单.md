# 系统验收清单

仅记录已实现系统的关键功能与核心数值，不记录小细节调整及普通 bug 修复。勾选由用户或用户明确授权的 AI 完成；核心规则变化或原验收结论失效时，相关系统项需重新验收。

## 系统功能验收清单

- [ ] **货币商店**：主界面商店入口打开 `CurrencyShopUI`，支持钻石与 Robux 页签；钻石页每组显示下一档，点击后打开 `ShopPurchaseUI` 展示商品、图标及钻石价格，确认购买后由服务端检查顺序、余额并扣款，请求期间禁点、失败允许重试、成功禁用购买，关闭返回列表，重复请求不重复升级；主界面右侧倍率按钮打开下一档确认页，力量包前两档打开同一确认页，价格与可发训练值按配置及永久加成刷新，经验已满时禁购且服务端拒绝扣款，第三档暂时隐藏；训练倍率与随身容量永久保留，重生和重登恢复；Robux 页展示钻石包与周卡，配置真实 `RobloxProductId` 后使用平台支付，未配置或无法读取平台价格时禁购；仅服务端收据发奖并去重保存，周卡进入原生背包后使用激活。入口：[商店界面](../StarterPlayerScripts/Client/UI/CCurrencyShopUICompClass.luau)、[单件购买页](../StarterPlayerScripts/Client/UI/CShopPurchaseUICompClass.luau)、[购买处理器](../ServerScriptService/Server/Handlers/BuyHandlers.luau)。

- [ ] **小狗 NPC**：世界 1 前五区随机选不同区域刷新公共小狗，保持原地黄金描边与旋转；任意已就绪且存活的玩家可近距离拾取，竞争拾取只成功一次，成功消失并增加 GetDog 每日任务进度，不增加 GetItem 普通道具进度、不进入背包；到期清理旧批次，抢完不提前补刷。入口：[小狗服务](../ServerScriptService/Server/Service/SDogNpcServiceClass.luau)。

- [ ] **世界传送**：世界 1–3 的金色传送门均打开同一世界列表，离开关闭；服务端按历史最高训练等级校验解锁，重生与重登保留资格，旧存档按当前等级和上次重生门槛补齐历史等级；按配置落点传送并同步当前世界；世界 2、3 配置出生垫板，仅作落点标记，不启用随机出生。入口：[世界配置](../ReplicatedStorage/Scripts/Game/Shared/GameEnum.luau)、[传送入口](../StarterPlayerScripts/Client/UI/CWorldTeleportUICompClass.luau)。

- [ ] **福利**：主界面福利入口打开 `WelfareUI`；显示离线训练奖励、在线奖励、累计七日登录、每日登录钻石及每日任务；任务按成功拾取件数、累计在线分钟和当天曾同服的不同好友累计人数记录进度，不要求好友同时在线，同一好友每天只计一次；每项每天领取一次，进度、好友去重记录和领取状态重登保留、UTC 跨日重置；奖励按现有配置发放，容量不足保留领取资格；在线时长当天累计、重进保留、跨日重置，累计登录漏登不清零；两种周卡从原生背包使用后即时发奖，次日起与每日登录福利一起领取，续卡保留当天领取状态、剩余次数重登恢复。离线奖励按服务端记录的离服时间生成批次，每个 UTC 日最多领取一次，单倍与暂时免费双倍互斥；重复请求不重复发奖，领取记录与未领取批次重登保留，打开时优先显示离线页，当天领取后下次打开隐藏；旧存档无离服时间不追溯。入口：[福利界面](../StarterPlayerScripts/Client/UI/CWelfareUICompClass.luau)、[服务端活动](../ServerScriptService/Server/Player/SActivityCompClass.luau)。

- [ ] **训练基地**：进入 Training1–Training5 已解锁训练台自动训练，客户端挥镐并显示训练状态与收益；未解锁提示重生门槛，离开、传送、死亡或角色更换后停止原场地收益；服务端位置与解锁检查，不接受客户端指定倍率。入口：[训练结算](../ServerScriptService/Server/Player/SMiscCompClass.luau)。

- [ ] **武器商店**：进入世界 1 的 `Workspace.PurpleHut.Trigger`，或世界 2、3 的 `Workspace.Decorations.World2Shops/World3Shops.PurpleHut.Trigger` 打开同一 `WeaponShopUI`，支持小屋流入、流出及各世界购买与装备提醒；离开关闭，手动关闭后留在区域内不反复弹出；按 `ToolConfig` 显示名称、图片、价格与训练倍率；默认解锁并装备 101，服务端金币购买永久解锁，购买的武器训练倍率高于当前装备时自动装备，相同或更低时保留当前装备，已装备武器不能卸下，重复购买不重复扣款；切换装备替换手持模型并保留攻击动画与拖尾，重生和重登恢复装备。入口：[武器界面](../StarterPlayerScripts/Client/UI/CWeaponShopUICompClass.luau)、[服务端武器](../ServerScriptService/Server/Player/SWeaponCompClass.luau)。

- [ ] **GM 管理**：仅开发者 ID 白名单玩家显示主界面 GM 按钮并打开面板；服务端独立校验身份，只操作本人数据；支持设置等级、重生次数、金钱、钻石、按道具 ID 与数量添加道具、二次确认重置数据与立即保存；添加道具校验配置与背包容量，操作结果和保存失败正确反馈。入口：[GM 业务组件](../StarterPlayerScripts/Client/UI/CGMIntegrationCompClass.luau)。

- [ ] **石头关卡**：客户端自动攻击、预测个人血量，服务端按命中时等级计算减伤后的累计伤害并回传剩余血量，客户端据此决定击碎和请求掉落，普通攻击在下砸时命中；秒杀关卡允许无碰撞穿行，经过石头即触发击碎，不等待挥砍或收招，服务端认可后显示击破；站立和移动时保持金色爆气，离开或失去条件时结束；服务端按玩家和轮次在首次进入区域时预生成普通、幸运及空石头内容；离开后重进不补充，击破只揭露已定内容；关卡内隐藏整条经验条，仅显示居中回家按钮，服务端校验后返回基地出生点，基地恢复等级经验条；回基地边沿结束本轮并恢复个人石头，角色更换只恢复满血石头与已击破快照，不重抽；无效命中撤销本地扣血。入口：[客户端石头组件](../StarterPlayerScripts/Client/Player/CRockLevelCompClass.luau)、[服务端石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.luau)。
- [ ] **等级与训练**：走路和有效击打获得训练值并升级；点击不增加实际收益；主界面正确显示等级、力量和经验，重登恢复训练进度。入口：[杂项组件](../ServerScriptService/Server/Player/SMiscCompClass.lua)、[主界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CMainUICompClass.lua)。
- [ ] **道具与存储**：出生与重生获得镐子；区域预生成的收藏品按 `ItemData[itemId].DisplayModelId` 取模型，仅拥有者可拾取，未拾取掉落超时消失；服务器记录唯一掉落 ID、道具 ID、价格及幸运信息，拒绝伪造、过期及重复拾取；回基地将随身战利品存入玩家 KV，不进入原生背包或生成 Tool；满存储保留随身道具，重生与重登后价格、幸运属性和记录正确恢复。入口：[石头组件](../ServerScriptService/Server/Player/SRockLevelCompClass.luau)、[玩家数据](../ReplicatedStorage/Scripts/Game/Shared/PlayerDataConfig.luau)。
- [ ] **钻石**：主界面正确显示余额，重登保持存档余额。入口：[主界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CMainUICompClass.lua)。
- [ ] **道具出售**：进入世界 1 的 `Workspace.Shop.Trigger`，或世界 2、3 的 `Workspace.Decorations.World2Shops/World3Shops.Shop.Trigger` 出售区域自动打开同一 `LootSellUI`，支持小屋流入、流出；离开关闭，背包计数区不作为入口；只显示回基地存入 KV 的收藏品、真实图标及价格；全部出售与临时免费双倍出售由服务器校验稳定实例 ID 后结算，等待结果时禁止重复点击；成功删除对应 KV 记录并增加金币、释放存储容量，保留图鉴；随身战利品与普通背包物品不受影响，过期或重复请求不重复到账。入口：[出售界面](../StarterPlayerScripts/Client/UI/CLootSellUICompClass.luau)、[服务端结算](../ServerScriptService/Server/Player/SLootSellCompClass.luau)。
- [ ] **图鉴**：主界面打开 `CollectionUI`，展示全部 `ItemData` 道具；回基地成功入库后永久激活，普通与幸运版本共用一条图鉴，重复入库不增加种类，满包未入库不激活；已激活项显示名称及 `IconId` 图片，未激活项隐藏名称和图片；关闭后数据同步不重新打开，重登恢复记录。入口：[图鉴业务组件](../StarterPlayer/StarterPlayerScripts/Client/UI/CCollectionUICompClass.lua)、[入库激活](../ServerScriptService/Server/Player/SRockLevelCompClass.lua)。
- [ ] **光环商店**：进入世界 1 的 `Workspace.BlueHut.Trigger`，或世界 2、3 的 `Workspace.Decorations.World2Shops/World3Shops.BlueHut.Trigger` 打开同一 `AuraShopUI`，支持小屋流入、流出及各世界购买与装备提醒；离开关闭，手动关闭后留在区域内不反复弹出；服务端按 `AuraConfig` 金币购买并永久解锁，购买的光环训练倍率高于当前装备时自动装备，相同或更低时保留当前装备，未装备时购买后直接装备；单件装备、再次点击卸下，重复购买不重复扣款；服务端将配置粒子挂到角色身体部位，其他玩家可见，角色重生和重登恢复装备；品质读配置，图片暂用占位。入口：[光环界面](../../Game/StarterPlayer/StarterPlayerScripts/Client/UI/CAuraShopUICompClass.lua)、[服务端光环](../../Game/ServerScriptService/Server/Player/SAuraCompClass.lua)。
- [ ] **重生**：`RebirthUI` 模板缺失，客户端入口暂时停用，按钮显示开发中，待补齐模板后恢复预览与请求；服务端保留达标后经验归零、等级重置为 1 并增加一次重生的结算，货币与背包保留。入口：[重生界面](../StarterPlayer/StarterPlayerScripts/Client/UI/CRebirthUICompClass.lua)、[服务端结算](../ServerScriptService/Server/Player/SMiscCompClass.lua)。
- [ ] **本地化**：项目只维护英文；收藏品名称、品质、幸运掉落与拾取提示使用稳定 Key 和英文兜底；其他语言读取 Roblox 云端译文，缺失时使用本地英文；语言切换刷新当前掉落文案。新增动态 Key 是否已导入 Roblox 云端翻译表仍需确认。入口：[翻译模块](../StarterPlayer/StarterPlayerScripts/Client/Localization.lua)、[文案表](../ReplicatedStorage/Scripts/Game/Shared/Localization.csv)。

## 数值验收清单

- [ ] **货币商店**：沿用 Studio_Y3 当前上限，训练倍率顺序购买至 512 倍（9 档），钻石价依次为 28/38/48/78/228/418/758/1498/2688；倍率乘入走路、击打、训练台和力量卡收益，仍受原经验封顶约束。随身扩容 3 档各 +1，价格 52/368/688，与临时扩容卡叠加，不增加 KV 总存储上限。钻石包奖励 48/152/618/1698，48 包永久限购一次；右侧力量包 301/302 分别为 98/388 钻石、基础训练值 1800/7200，乘最高已解锁场地、永久训练、重生、图鉴、光环和武器倍率，不计在线追赶，实际收益截断至当前重生阶段经验上限，满经验不扣钻石；第三档不开放；周卡商品各发放对应道具 1 张。Robux 配置价仅供配置参考，界面使用平台价格。依据：[GoodsConfig](../ReplicatedStorage/Scripts/Game/Configs/GoodsConfig.luau)、[共享商店规则](../ReplicatedStorage/Scripts/Game/Shared/CurrencyShop.luau)。

- [ ] **小狗 NPC**：每批 3 只，每 180 秒换批，随机位置在各区域中心 80% 范围；模型高度 6 studs、底部离地 1 stud，每秒旋转 15°；拾取距离 10 studs，按住 E 0.5 秒，每只增加 1 次 GetDog 进度；每日拾取 10 只可领取 3 钻石，读取 ActivityConfig.DailyTaskConfig。依据：[GameEnum.DogNpcConfig](../ReplicatedStorage/Scripts/Game/Shared/GameEnum.luau)、[活动配置](../ReplicatedStorage/Scripts/Game/Configs/ActivityConfig.luau)。

- [ ] **世界传送**：世界 1 默认解锁，世界 2、3 分别需要历史最高训练等级 195、390 级；落点分别为 `(1, 2, 0)`、`(581, 2, 0)`、`(1161, 2, 0)`，出生垫板中心高度为 `-2`。依据：[世界配置](../ReplicatedStorage/Scripts/Game/Shared/GameEnum.luau)。

- [ ] **福利**：每日任务拾取 50/80 件分别奖励 3 钻石/105 道具 ×1，在线 30 分钟奖励 5 钻石，与 2 位好友同服奖励 2 钻石，读取 `DailyTaskConfig`；在线 5/10/20/25/35/45/55/65/75/90 分钟档位及累计七日奖励读取 `ActivityConfig`；每日基础钻石读取 `CommonConfig.LoginData.GemCount`（当前 5）；周卡 101/102 读取 `ItemConfig.KVTable`，即时 100/400 钻石、后续 6 次每天 30/120 钻石；未登录不扣次数、两卡独立叠加、每卡每天最多一次，首次激活当日不扣后续次数；离线时长上限读取 `CommonConfig.OfflineReward.Time`（14400 秒），单倍与免费双倍分别按 `Rate=0.25`、`VIPRate=0.5` 结算；复用最高已解锁训练场、永久训练倍率与重生倍率，不叠加在线追赶，经验不超过当前重生阶段上限；每日按 UTC 零点重置。依据：[活动配置](../ReplicatedStorage/Scripts/Game/Configs/ActivityConfig.luau)、[道具配置](../ReplicatedStorage/Scripts/Game/Configs/ItemConfig.luau)。

- [ ] **训练基地**：五个场地需要重生 0/3/6/9/12 次，倍率 1/2/5/9/14；场内每秒基础收益为 `trainingSettlementsPerSecond × 场地倍率`，替代走路与击打，再乘图鉴、光环、武器及重生倍率，沿用追赶和经验封顶；离场不补发积压收益。依据：[场地配置](../ReplicatedStorage/Scripts/Game/Configs/GameConfig.luau)。

- [ ] **武器**：价格与训练倍率读取 `ToolConfig.Price/TrainingRate`，默认 101 价格 0、倍率 1；仅已拥有并装备的单件武器提供倍率，与图鉴、光环倍率相乘后应用原有重生、追赶与封顶规则，不直接增加攻击力或金币；买入训练倍率更高的武器时自动装备，相同或更低时保留当前装备。依据：[武器规则](../ReplicatedStorage/Scripts/Game/Shared/Weapon.luau)、[训练结算](../ServerScriptService/Server/Player/SMiscCompClass.luau)。

- [ ] **石头关卡**：13 关血量、推荐等级、攻击力与等级差减伤符合[关卡配置与公式](../ReplicatedStorage/Scripts/Game/Shared/RockLevel.luau)；普通攻击与挥砍表现间隔 0.8 秒；达到满血秒杀条件时每 0.1 秒独立检查脚下及前方，最多命中一块，不受挥砍间隔限制，服务端认可后击碎。
- [ ] **等级与训练**：初始 1 级、最终上限 780，每阶段等级封顶于当前重生门槛，经验最多填满该等级；升级需求与累计经验符合[等级曲线配置](../ReplicatedStorage/Scripts/Game/Configs/NumericalConfig.lua)；每秒走路基础 +2、有效击打基础 +2，同时成立基础 +4，按重生倍率及追赶规则结算，点击不叠加收益。

- [ ] **钻石**：新玩家初始 500，已有存档余额不重置。依据：[玩家数据配置](../ReplicatedStorage/Scripts/Game/Shared/PlayerDataConfig.lua)。
- [ ] **图鉴**：按 `CommonConfig.CollectionData` 每收集 10 种不同道具增加 25% 训练收益；0～9 种无加成，10～19 种 +25%，20～29 种 +50%；图鉴倍率作用于走路和击打基础收益，再沿用重生倍率、追赶和经验封顶，不直接增加力量或货币。依据：[图鉴规则](../ReplicatedStorage/Scripts/Game/Shared/Collection.lua)、[训练结算](../ServerScriptService/Server/Player/SMiscCompClass.lua)。
- [ ] **光环**：价格与训练倍率读取 `AuraConfig.Price/TrainingRate`；未装备倍率为 1，已装备且解锁时使用该单件倍率，与图鉴倍率相乘后应用原有重生、追赶和封顶规则；不直接增加力量或金币，买入训练倍率更高的光环时自动装备，相同或更低时保留当前装备，未装备时购买后直接装备。依据：[光环规则](../../Game/ReplicatedStorage/Scripts/Game/Shared/Aura.lua)、[训练结算](../../Game/ServerScriptService/Server/Player/SMiscCompClass.lua)。
