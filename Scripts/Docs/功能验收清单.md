# 系统验收清单

- [ ] **统一奖励结算**：服务端礼盒、福利与任务整批奖励、登录初始赠送、在线/离线/点击/卡片训练、出售、钻石商品、付费收据、武器/光环解锁、容量卡和收藏品拾取统一通过 `FSRewardComp`；整批预检后执行，失败保留领取资格或恢复道具，购买消耗和奖励统一交换；既有身份校验、限速、重复领取防护及收据保存幂等保持。入口：[奖励组件](../ReplicatedStorage/Scripts/Framework/Server/Player/FSRewardCompClass.luau)、[项目奖励处理器](../ServerScriptService/Server/Handlers/RewardHandlers.luau)。

仅记录已实现系统的关键功能与核心数值，不记录小细节调整及普通 bug 修复。勾选由用户或用户明确授权的 AI 完成；核心规则变化或原验收结论失效时，相关系统项需重新验收。

## 系统功能验收清单

- [ ] **好友邀请提醒**：每次进服客户端初始化满 60 秒后仅检查一次在线好友，排除本服务器玩家，随机选择一位可邀请好友，通过原生右下角通知显示头像、名字与邀请/关闭按钮，显示 12 秒；无候选好友、平台不允许邀请或查询失败时不弹。点击邀请再次校验资格并打开针对该好友的官方邀请确认窗口，重生不重置计时、不重复提醒。动态文案已声明翻译，收集与语言验收待核对。入口：[好友邀请组件](../StarterPlayerScripts/Client/Player/CFriendInviteCompClass.luau)。

- [ ] **玩家行为上报**：接入主新手实际动作完成漏斗 FirstLootV2、成长里程碑、Robux 商店购买漏斗及各购买阶段的服务端钻石余额，保留光环/镐子和钻石商店成功消费及首付累计在线。新手仅从开始点建立流程，持久进度去重，旧测试档不补报后半段；引导结束不代表领取奖励。成长按引导完成、首次重生、世界 2/3 解锁推进；购买按进店、选商品、发起支付弹窗、收据发奖并保存成功推进。登录完成后计时，离服清理前补齐在线时间；新收据分析元数据随奖励保存，保存失败重试保留原快照，历史重放不重复上报；Studio、开发白名单及配置测试账号不进入正式统计，分析异常不改变业务结果。运行与正式后台尚未验收。入口：[上报组件](../ServerScriptService/Server/Player/SAnalyticsCompClass.luau)、[报表使用说明](玩家行为上报使用说明.md)。

- [ ] **同服好友训练加成**：服务端平台好友服务统计当前同服好友，加入、退出及关系刷新后结算采用当前人数；与每日任务累计好友进度独立，客户端同步人数用于力量包预览。

- [ ] **新手引导**：仅新玩家开启；收集任意 2 件、回基地入库、出售、购买训练倍率、装备更强武器、训练说明提醒、鼓励提示、奖励入口提醒依次推进；第 6 步不要求进入训练台，第 8 步用 UI 箭头指向主界面左侧奖励图标，不要求点击或领取，最后三步各显示 3 秒后自动推进。主流程完成后，买得起强于已拥有最强装备的未购买镐子或光环时，主界面持续显示对应英文购买提示并自动本地化，同一套箭头指向商店；两类均可升级时镐子优先，余额不足、购买或全部解锁后及时切换或隐藏。服务端真实结果或提醒计时推进并持久保存，重登续接，已完成不重播；客户端英文提示复用本地化入口，空中 Beam 箭头连接角色与目标并显示流动彩虹渐变。道具生成规则保持原样，进入第一关后，从本轮已预生成的道具中选择距进入位置最近的一件并锁定，石头击破变为掉落时保持原坐标；拾取、销毁或过期后才重选，回基地重置轮次后等待再次入关，入关前不显示道具箭头；拾取其他道具同样计入进度。死亡、退出与析构清理。入口：[步骤配置](../ReplicatedStorage/Scripts/Game/Shared/TutorialGuideConfig.luau)、[引导表现](../StarterPlayerScripts/Client/Player/CTutorialGuideCompClass.luau)。
