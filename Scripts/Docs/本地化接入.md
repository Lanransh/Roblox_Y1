# 项目本地化

编码智能体使用 [Roblox 项目本地化 skill](../.agents/skills/roblox-localization/SKILL.md)。
本文区分代码接入、动态文案上传、固定文字采集和最终验收，不要求 AI 通过
Roblox MCP 维护翻译表。

## 整体流程与分工

1. UI 模板中有 `AutoLocalize` 属性的节点默认开启，包含父级容器，文字使用英文。
2. 仅由客户端脚本在运行时对自己翻译的动态文字节点执行
   `AutoLocalize = false`，再通过 `Text.Tr()` 查译文并替换参数；
   Studio 编辑态节点、模板和导入数据保持 true，服务端不翻译。
3. 动态原文和参数模板由翻译工具收集，上传 Roblox 云端供脚本读取。
4. Studio 开启 Automatic Text Capture（ATC），经授权试玩并展示固定文字，
   让采集结果进入云端；再确认目标语言译文状态。
5. 验收英文兜底、目标语言、参数、语言切换及长译文布局。

第 1 项是 Studio 编辑态模板设置，第 2 项是客户端脚本运行时设置。不要在
Studio 属性面板或通过 MCP 关闭节点属性，也不要把 false 保存进模板或导入
数据。不要关闭整个界面的自动本地化，也不要用批量开启
覆盖动态节点的 false。节点及祖先均不能阻断固定文字的自动本地化。

本技能指导代码处理第 1、2 项，并为第 3 项提供原文标记与配置字段来源。
云端上传、试玩采集和验收另行执行；保存脚本不代表这些环节已完成。

## 加载 Text

模块为 `ReplicatedStorage/Scripts/Game/Shared/Text.luau`，框架初始化后加载：

```lua
local FX = _G.FX
local FXLoader = FX.Loader
local Text = FXLoader:RequireShared("Scripts/Game/Shared/Text")
```

`Text.Mark()` 两端只返回原文。`Text.Tr()` 仅客户端可用，复用入口创建的
`FC.Localization` 读取玩家语言译文并格式化，无译文时回退英文；原文自身作为
翻译 Key。调用须在翻译对象初始化后、释放前，服务端调用会报错。

## 固定文字与动态文字

```lua
-- 固定标题：即便由脚本赋值，仍可让引擎自动本地化。
title.AutoLocalize = true
title.Text = "Inventory"

-- 客户端脚本运行时关闭动态节点；Studio 编辑态模板保持 true。
label.AutoLocalize = false
label.Text = Text.Tr("Strength: {value}", {
    value = GameUtility.NumberToText(strength),
})
```

代码负责创建、克隆或绑定节点时，就要明确该节点的翻译归属；不编辑 Generated
脚本。`Text.Tr()` 不自动设置节点，也不自动绑定 UI。动态界面订阅共享翻译
对象的 `Changed`，在云端加载或语言变化后用原文及参数重新求值，连接随组件清理。

## 服务端提示及配置文本

```lua
local message = Text.Mark("You received {amount:int} Coins")
self:GetPlayerObject():ShowLocalizedTips(message, {amount = amount})
```

客户端提示接收端使用 `Text.Tr()`，由客户端脚本运行时关闭提示文字节点的
自动本地化，Studio 编辑态模板保持开启，刷新不重置计时。普通 `ShowTips()`
只展示已准备好的文字，不自动翻译。

原文存变量、函数返回或经网络传递时，在定义处使用 Mark 字面量。
配置名称、描述保持普通字符串，通过工具指定字段收集，客户端使用
`Text.Tr(config.Name)`。不依赖追踪客户端变量，也不手改生成配置文件。

完整模板与参数分开，不先拼句子再翻译。名称参数先在客户端翻译再传入整句；
数量缩写复用 `GameUtility.NumberToText` 并使用 `{value}`，整数使用 `{count:int}`。
格式化结果不参与计算、存档或发奖；玩家显示名与业务查找标识分开。

## 上传、ATC 与验收

动态文案与固定 UI 是两条来源：动态模板经工具上传；固定 UI 通过 ATC 采集。
ATC 只采集启用 AutoLocalize 的文本对象，不能代替动态模板的上传；TextBox
只采集 PlaceholderText，不采集玩家输入的 Text。固定界面必须实际展示才能
覆盖采集，采集入表还需另查目标语言译文。新 Studio 会话需重新启用 Studio ATC。

收集工具尚未实现。AI 不通过 Roblox MCP 维护翻译表，不在编码任务中手工修改
翻译 CSV、上传云端或启动试玩。分别报告代码接入、动态文案上传、ATC 覆盖及
最终验收的实际状态，不把编译或 Script Sync 核对当作翻译已生效。

平台语义参考：[AutoLocalize](https://create.roblox.com/docs/reference/engine/classes/GuiBase2d/AutoLocalize)、
[ATC](https://create.roblox.com/docs/production/localization/automatic-translations)、
[脚本本地化](https://create.roblox.com/docs/production/localization/localize-with-scripting)。
