# Roblox TemplatePage UI 设计规范

以 [Roblox_Template](https://www.figma.com/design/C2sWorZXq7L5Kxlm0JE02w/Roblox_Template?node-id=0-1) 的 `TemplatePage` 为模板来源，整体风格与 `RebirthStudUI` 一致：红色 Stud 标题栏、半透明深色主体、白字深描边、绿色普通操作、紫色付费操作、红色进度条。

本次更新替代旧版蓝色窗框、悬浮标题牌、蓝色普通按钮、金色付费按钮及青绿色进度条规则。下文标为“参考值”的参数来自当前模板；“推荐值”用于真实游戏界面的扩展。

## 一、基础约束

- UI 根画布：`1280x720`；页面与根画布背景纯白 `#FFFFFF`。
- 使用 Fixed layout，禁用 Auto Layout；交付静态 UI。
- 普通 UI 文本最小字号 `16`，保持可编辑，映射为 Label。
- 按钮仅允许内投影；普通文本不使用阴影、发光或模糊，允许清晰描边。
- 所有游戏 UI 统一使用 Stud 材质语言，适用部位为标题栏、普通操作按钮、进度条及有色实体底板；关闭按钮明确不使用 Stud。
- 半透明主体、透明内容区、文字、图标、细描边和白色根画布不叠加 Stud，避免妨碍透景和识别。
- **Stud 只使用宿主节点自身的 IMAGE / TILE 填充。禁止为它新增 `StudTextureImg`、矩形、Frame、蒙版或其他专用纹理节点。**
- 引擎原生可表达的底色、文字、圆角、描边等保留独立可编辑属性，不把整个按钮连文字烘焙成图片。

## 二、TemplatePage 复用规则

- `TemplatePage` 是窗口、标题、关闭按钮、操作按钮和进度材质的来源；真实游戏 UI 放在 `GameUIPage`。
- 模板参考 UI：`SmallWindowUI`、`MediumWindowUI`、`LargeWindowUI`、`OperationButtonExamplesUI`。
- 标题主组件为 `TitleImg`（节点 `1:24`）；旧可见组件 `TitleBox` 已更名。窗口中的 `TitleBox` 现在只承担透明结构容器职责。
- 复用 `TitleImg` 与 `CloseBtn`（节点 `1:30`），不要重新手绘另一套。标题背景可按窗口宽度调整，`TitleTxt` 独立可编辑。
- 进度样式参考 `ProgressBarImg`（节点 `1:49`），长度可按布局重做，不要求固定长组件。
- 复用组件时保留实例关联；检查既有 overrides，确保旧配色或效果没有覆盖新模板。

## 三、三档窗口尺寸

参考值，位置均相对各自父节点：

| 模板 | PopupPanelImg 尺寸 / 根内位置 | TitleBox 尺寸 / 根内位置 | CloseBtn 标题内位置 |
| --- | --- | --- | --- |
| SmallWindowUI | 650×310 / (315,240) | 650×70 / (315,170) | (588,9) |
| MediumWindowUI | 780×380 / (250,205) | 780×70 / (250,135) | (718,9) |
| LargeWindowUI | 820×450 / (230,170) | 820×70 / (230,100) | (758,9) |

统一结构：

```text
SmallWindowUI / MediumWindowUI / LargeWindowUI
├─ PopupPanelImg
└─ TitleBox
   ├─ TitleImg
   ├─ TitleTxt
   └─ CloseBtn
      └─ CloseIconTxt
```

标题栏与透明主体是根节点下两个独立模块，等宽、左右齐平，主体紧接在标题栏下方，不互相覆盖；主体外框不得包住标题栏。主体只有 PopupPanelImg 一层底板，实际内容直接放在它内部，不再嵌套 ContentImg。推荐内容距主体顶部 16、左右至少 10。关闭按钮属于标题栏，位于右端前景层。

## 四、窗口颜色与厚度

### `PopupPanelImg`

参考值：

- 填充：`#10231B`，填充不透明度 `0.18`。
- 描边：`#16291E`，不透明度 `0.9`，粗细 `2`。
- 圆角：`2`；无阴影；不叠加 Stud。
- 修改填充透明度，不修改整个节点 opacity，以免让子文字和按钮一起变淡。

### `TitleBox`

透明结构容器，不承担可见底色、描边和效果。自身使用 Box 后缀，内部 `TitleImg` 承担可见红色顶栏，详见第五节。

### 单层内容承载

- 三档窗口已移除内层 `ContentImg`；仅由 `PopupPanelImg` 承担主体背景、描边和内容承载。
- 不再叠加第二层整窗内容底板，主体填充不透明度保持 `0.18`。
- 只有实际功能分区需要时才增加局部卡片；不要为承载内容添加无职责的包装节点。
- 白底预览会呈浅灰；实际透景效果应在用户提供或授权的场景背景上判断，不把场景烘焙进 UI。

## 五、标题模板

参考值：

- `TitleImg` 主组件：`320×70`；窗口实例扩展到对应标题栏宽度。
- 填充：`#DF1A23` + Stud TILE；图片填充不透明度 `1`，重复间距 `27 px`。
- 外框描边：黑色 `#000000`，粗细 `3`，位置 Outside；圆角 `2`。
- 标题栏保留纯黑外框；仅在填充区域内侧顶部和左侧添加约 `2 px` 渐隐高光，白色 alpha 分别从 `0.42`、`0.25` 衰减到 `0`。
- 内侧高光使用标题自身的线性渐变填充，不新增节点；不使用外发光或会覆盖黑色描边的投影效果，`effects` 保持为空。Stud 纹理保持不变。
- 底部黑框内侧保留约 `3 px` 深色厚边，向上用 `1 px` 过渡；使用标题自身的线性渐变填充，深色 `rgba(31,0,4,0.72~0.8)`。上亮下暗形成厚度，不向外投影，不增加节点。
- 背景不再包含旧版装饰多边形、高光条或内嵌底板散件。

`TitleTxt` 参考值：

- 字号 `30`、粗体、左对齐、垂直居中。
- 白色 `#FFFFFF`；外描边 `#000000`，粗细 `2`；无文字阴影。
- 标题栏内位置 `(24,0)`，高度 `70`，宽度为标题栏宽减 `112`，为关闭按钮留出空间。
- 与 `TitleImg` 同属 `TitleBox`，文字排在背景之后。

## 六、关闭按钮

复用 `CloseBtn` 主组件，参考值：

- `52×52`，圆角 `6`，绿色底 `#55CE35`，白色关闭符号。
- 关闭按钮不使用 Stud，仅保留纯绿色底、黑色外框及白色黑描边符号。
- 按钮外框描边 `#000000`，粗细 `3`，位置 Outside；节点尺寸 `52×52`，含描边视觉尺寸 `58×58`，四边保持完整黑框。
- 关闭按钮不使用内高光或内压边，避免绿色效果覆盖黑色外框。

- 结构仅保留按钮与 `CloseIconTxt`，不再套一个小红色核心方框。
- `CloseIconTxt`：`×`，Inter Extra Bold，字号 `52`，白色 `#FFFFFF`；黑色 `#000000` 外描边 `2`，无阴影。
- 文字框 `52×52`，位置 `(0,-2)`，水平/垂直居中。

## 七、OperationButtonExamplesUI 按钮规范

参考值：

- 按钮 `220×58`，圆角 `6`，描边 `3`。
- 底色叠加 Stud TILE，重复间距 `27 px`，图片不透明度 `1`。
- 文字字号 `24`、粗体、水平/垂直居中；白色 `#FFFFFF`，`#192215` 外描边 `1.5`，无阴影。
- 顶部内高光：白色 alpha `0.45`，offset `(0,4)`，radius `0`。
- 底部内压边：对应按钮描边色 alpha `0.65`，offset `(0,-6)`，radius `0`。

| 按钮 | 语义 | 底色 | 描边 |
| --- | --- | --- | --- |
| ConfirmBtn | 确定、普通主操作 | #67ED14 | #225A07 |
| CancelBtn | 取消、返回 | #638079 | #263E36 |
| BuyBtn | 普通购买 | #67ED14 | #225A07 |
| PaidPurchaseBtn | 付费购买、跳过、充值 | #D03BF2 | #691582 |
| EquipBtn | 装备、启用 | #67ED14 | #225A07 |

结构为 Btn Frame（底色 + Stud 填充 + 描边/内投影）与 Txt 子节点。材质不增加任何子节点；真实功能图标可保留。

## 八、内容区布局与材质建议

推荐值：

- 内容模块间距 `16~24`，文本与控件间距 `8~12`。
- 透明区域优先白字加深色描边，不使用低对比度灰字。
- 收益提升可用亮绿数字，如 `#9AFF52`，并加深色描边。
- 新增有色实体卡片统一使用内联 Stud；半透明内容容器保持通透，不密铺纹理。
- 功能优先，避免多层底板套叠；主体、标题、主操作之间建立明确强弱关系。

### Stud 统一材质

参考值：

- 透明源单元 `32×32`，凸块约 `16×16`，圆角 `2`。
- 模板采用 `96×96` 透明 PNG；27 px 平铺对应 `scalingFactor = 27 / 96`。
- 左上亮、右下暗：亮边白色 alpha `0.28`，暗边黑色 alpha `0.19`，正面白色 alpha `0.07`。
- 新界面继承模板自身的图片填充；不同 Figma 文件不能依赖旧文件里的节点 ID 或图片 hash。
- 只调 Stud 的图片填充 opacity，不降低整个按钮 opacity。素材 alpha、填充 opacity、宿主和祖先 opacity 会连乘。
- 材质随宿主尺寸、圆角和裁切显示；不得为独立边距添加纹理节点。
- 同一节点只保留一份 Stud 填充，禁止重复叠加；不要误删其他用途的图片填充。
- SVG / PNG 源资产位于 `F:/MiniGame/StudioGameToolkit/AgentWorkspace/Figma/.agents/skills/figma-stud-effect/assets/`，方法见该目录上级的 `SKILL.md`。

## 九、进度条规范

参考值：

- `ProgressBarImg`：`520×54`，底色 `#571018`，描边 `#20231C`、粗细 `3`，圆角 `6`。
- `ProgressFillImg`：满值铺满 `520×54`，底色 `#FF2B35`，圆角 `6`。
- 底图和填充均使用内联 Stud，27 px 重复间距，图片不透明度 `0.75`。
- 底图/填充仅有底部内压边：`rgba(128,0,0,0.5)`，offset `(0,-5)`，radius `0`。
- 不加整体顶部高光或单独高光条；Stud 单元自身的微小亮边属于纹理。
- `ProgressTxt` 白色、粗体、居中，`#30090D` 外描边 `1.5`，无阴影。
- 只制作满值，文字使用 `进度值 / 目标值`；不使用百分比。
- 实际长度可按布局调整，数值与裁切变化交由引擎运行时处理。

结构：

```text
ProgressBarImg
├─ ProgressFillImg
└─ ProgressTxt
```

## 十、字体与字号

- 全部普通文字不小于 `16`；保留模板中可用的字体族和粗体字重。
- 模板标题 `30`，操作按钮 `24`，关闭符号 `52`。
- 推荐正文 `18~24`，辅助说明 `16~20`，核心倍率 `36~48`。
- 白字配深描边保证透景时可读；不使用文字阴影、发光、模糊。
- 文本仍映射为 Label，不参与 Stud 图片烘焙。

## 十一、新增界面执行顺序

1. 定位此 Roblox 模板的 TemplatePage，按内容选择三档窗口。
2. 复用横向 TitleImg、TitleTxt 和 CloseBtn，保留模板的父子层级。
3. 主体采用单层深色低不透明度底板，实际内容直接放入 PopupPanelImg，不嵌套整窗内容底板。
4. 按语义复用绿、紫、灰绿、橙红操作按钮。
5. 标题、普通操作按钮、进度条和新增有色实体底板使用宿主内联 Stud 填充；关闭按钮保持纯色。
6. 保持进度满值状态、文本可编辑，不新增 Stud 纹理节点。
7. 按各 UI 根节点运行 figma-ui-self-check，修复问题。
8. 截图检查纹理密度、文字描边、标题/关闭按钮间距以及透明度；检查不增加导出层级。

## 十二、禁止项

- 禁止使用旧版蓝色窗框、悬浮标题牌和小红芯套框关闭按钮替代本模板。
- 禁止为 Stud 新建任何专用节点、蒙版或大量重复矢量块。
- 禁止把按钮、文字、图标、场景一起烘焙到纹理图片。
- 禁止给透明内容容器和文字盲目铺 Stud，或为了加强纹理改变整个宿主 opacity。
- 禁止按钮外投影、文字阴影、发光和模糊。
- 禁止 Auto Layout、非规范命名、小于 16 的普通文字。
- 禁止制作非满值进度状态和百分比文案。
